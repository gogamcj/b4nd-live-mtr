## 4. 장시간·장애 주입 시나리오 (Phase 14)

1. 2시간 30분 세트리스트 반복 재생, 1분마다 CPU/메모리/xrun 기록
2. 재생 중 USB MIDI 분리 → 재연결: 해당 트랙만 무음, 복귀 후 프리셋 재전송
3. 재생 중 오디오 인터페이스 분리: 즉시 정지, 노트 걸림 없음, 같은 장치 재연결
4. 미디어 파일 삭제 후 프로젝트 열기: Live Mode 진입 차단
5. 백그라운드 CPU 부하(다른 프로그램) 중 재생: xrun 카운트·로그
6. 강제 종료 후 재실행: 마지막 곡/위치 복원 제안
7. 절전/화면보호기: Live Mode에서 시스템 절전 차단(`SetThreadExecutionState`) 확인
